A one-line family scene, warm, funny and heartfelt: Dad saves the burnt toast for himself, calls it "the crispy one," and Mom pretends not to notice — so the rest of us get the good slices. The program writes the scene to `/output/entry.txt` (one line, 160 characters, inside the 280-character gate).

## Run it

```sh
python3 main.py
```
